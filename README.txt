SREE VEERABHADRA HOMEMADE FOODS - CLEAN LAUNCH VERSION

This version contains no built-in demo or sample products.

DEPLOY WITH GITHUB DESKTOP
1. Extract this ZIP.
2. Copy everything inside the extracted folder into your cloned
   sree-veerabhadra-pickles repository folder.
3. Choose Replace the files in the destination.
4. In GitHub Desktop, commit with: Remove demo products
5. Click Push origin.
6. Wait 1-2 minutes, then refresh the website with Ctrl + F5.

PRODUCTS
- When Firestore contains no products, the storefront displays
  "Products coming soon".
- Add real products later through the existing Admin Portal.
- Products already stored in Firebase are not deleted by replacing website
  files. Delete any old test products from the Admin Portal if they still
  appear after deployment.

PRESERVED
- Firebase configuration and authentication
- Admin product and order management
- Cart and checkout
- COD and UPI support
- Customer account pages
- Product photo folders and upload workflow
